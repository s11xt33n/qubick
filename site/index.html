Гибридные квантово-классические нейронные сети

Собственная библиотека qhnn на PyTorch и систематическое исследование: когда квантовый слой в нейросети действительно даёт выигрыш, а когда классическая модель того же размера справляется не хуже.

О проекте

Зачем это исследование

Квантовые нейросети — одно из самых обсуждаемых направлений машинного обучения. На практике они почти всегда гибридные: классическая сеть готовит признаки, параметризованная квантовая схема их преобразует, классический слой выдаёт ответ. Все параметры обучаются вместе.

Открытый вопрос — приносит ли квантовая часть пользу, или тот же результат даёт обычная сеть сопоставимого размера. Честный ответ требует аккуратного протокола: много запусков, модели одинакового размера, контрольные архитектуры и проверка статистической значимости.

Проект отвечает на этот вопрос на табличных данных и на изображениях, включая медицинские снимки, где данных обычно мало — именно там компактные квантовые модели могли бы проявить себя.

Исследовательские вопросы

  1. Малые выборки. Даёт ли квантовая голова выигрыш, когда обучающих примеров мало (50–500)?
  2. Обучаемость. Как бороться с barren plateaus — затуханием градиентов в больших схемах?
  3. Практичность. Насколько гибрид устойчив к шуму и конечному числу измерений реального квантового процессора?

    Программная часть

    Библиотека qhnn

    Собственная реализация, а не обёртка над готовыми инструментами: батчевый симулятор вектора состояния на PyTorch, обучаемый квантовый слой, два способа вычисления градиентов и воспроизводимая инфраструктура экспериментов на CPU и GPU.

    ⚛

    Симулятор на PyTorch

    Весь батч исполняется одновременно, на CPU и GPU; градиенты — штатный autograd. До 20 кубитов на Tesla V100.

    ∂

    Два способа градиентов

    Backprop для симуляции и parameter-shift — как на реальном квантовом процессоре. Режим конечного числа измерений (shots).

    ✓

    Проверенная корректность

    158 автотестов: совпадение с PennyLane на 96 конфигурациях схем, parameter-shift ≡ backprop.

    ⊞

    Гибкий квантовый слой

    3 способа кодирования, 3 анзаца, data re-uploading, 3 стратегии инициализации — как обычный nn.Module.

    ⇄

    Экспорт в OpenQASM

    Обученную схему можно выгрузить в OpenQASM 2.0 и запустить на реальном квантовом оборудовании.

    Воспроизводимые эксперименты

    YAML-конфиги, 10 seed на точку, параллельный запуск на 80 потоках и GPU, продолжение после сбоя.

    Пример использования

    import torch
from torch import nn
from qhnn import QuantumLayer

model = nn.Sequential(
    nn.Linear(512, 4), nn.BatchNorm1d(4), nn.Tanh(),  # encoder
    QuantumLayer(n_qubits=4, n_layers=2),              # 4 → 4
    nn.Linear(4, 10),                                  # head
)
loss = model(torch.randn(32, 512)).sum()
loss.backward()   # градиент проходит через квантовую схему

    7Barren plateaus

    Дисперсия градиента по параметру схемы при случайной инициализации. Экспоненциальное затухание с ростом числа кубитов делает обучение больших схем практически невозможным (McClean et al., 2018); для глобальной функции стоимости эффект сильнее (Cerezo et al., 2021).

    Находка

    Масштаб энкодера может «выключить» квантовый слой

    В первой версии гибрида классический encoder отображал признаки в углы через π·tanh. На изображениях (512 признаков) оптимизатор быстро раздувал веса encoder'а, tanh насыщался, и углы упирались в ±π. Но RY(π)|0⟩ и RY(−π)|0⟩ отличаются лишь глобальной фазой — квантовая схема их не различает, и информация о входе теряется: модель падала до уровня случайного угадывания. Замена на (π/2)·tanh (как у Mari et al., 2020) и нормализация BatchNorm перед ней устраняют эффект.

    Hybrid QNN: accuracy при разных encoder'ах

    Почему это важно

    Классическая «bottleneck»-модель с тем же encoder'ом от насыщения почти не страдает: знак ±π она различает. Поэтому сравнение «гибрид против классики» с неудачным encoder'ом систематически и незаметно занижает квантовую модель — и приводит к ложному выводу «квантовый слой бесполезен».

    Вывод для практики: диапазон углов кодирования должен исключать эквивалентные состояния, а масштаб входа квантового слоя стоит контролировать нормализацией. Этот эффект будет отдельно исследован в диссертации.

    Протокол экспериментов

    • Разбиение. Табличные данные — стратифицированно 60 / 20 / 20 % (обучение / валидация / тест). Изображения — фиксированный тест, из обучающей части берётся стратифицированная подвыборка нужного размера (50–2000), 20 % её идёт на валидацию.
    • Предобработка. StandardScaler, обученный только на обучающей выборке. Для чистой квантовой модели признаки сжимаются PCA до числа кубитов (тоже только по обучающей выборке) — без утечки информации из теста.
    • Повторы. 10 seed на каждую конфигурацию (0–9); seed задаёт и разбиение данных, и инициализацию модели.
    • Обучение. Adam, lr = 0.01, батч 32 (64 для 12 кубитов), кросс-энтропия, до 300 эпох (150 для изображений) с ранней остановкой по loss на валидации (терпение 30 / 20 эпох) и возвратом лучших весов.
    • Метрики. Accuracy и macro-F1 на тесте; доля предсказываемых классов (выявляет «схлопывание» модели в один класс).
    • Честное сравнение. MLP с тем же числом параметров, что у гибрида, и bottleneck-модель — гибрид без квантовой части.
    • Статистика. Парный тест Уилкоксона по seed (гибрид против каждой модели), уровень значимости 0.05.

    Программы и оборудование

    • Python 3.12, PyTorch 2.14 (CUDA 12.6), scikit-learn 1.9, NumPy 2.5, pandas 3.0.
    • PennyLane 0.45 — только как эталон для проверки корректности собственного симулятора (158 автотестов).
    • Сервер: 2 × Intel Xeon E5-2698 v4 (80 потоков), 64 ГБ RAM, NVIDIA Tesla V100-SXM2 16 ГБ, Windows 11.
    • Каждая конфигурация эксперимента задана YAML-файлом; идентификатор запуска — хеш всех его параметров.
