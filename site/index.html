Гибридные квантово-классические нейронные сети

Разработка библиотеки qhnn на PyTorch и экспериментальное исследование: когда квантовый слой в нейросети действительно помогает, а когда хватает классической модели того же размера.

    Библиотека qhnn

    Собственная реализация, а не обёртка: батчевый симулятор вектора состояния на PyTorch, обучаемый квантовый слой, два способа вычисления градиентов и воспроизводимая инфраструктура экспериментов.

    Возможности

    • Симулятор — весь батч исполняется одновременно, CPU и GPU, autograd PyTorch
    • QuantumLayer как обычный nn.Module: 3 кодирования, 3 анзаца, data re-uploading
    • Градиенты: backprop и parameter-shift (как на реальном квантовом процессоре), режим конечного числа измерений
    • Проверка корректности: 158 автотестов, совпадение с PennyLane на 96 конфигурациях схем
    • Экспорт в OpenQASM 2.0 для запуска на реальном оборудовании
    • Эксперименты по YAML: параллельный запуск, продолжение после сбоя, CPU + GPU

    Пример

    import torch
from torch import nn
from qhnn import QuantumLayer

model = nn.Sequential(
    nn.Linear(30, 4), nn.Tanh(),           # encoder
    QuantumLayer(n_qubits=4, n_layers=2),  # 4 -> 4
    nn.Linear(4, 2),                       # head
)
loss = model(torch.randn(8, 30)).sum()
loss.backward()   # градиент проходит через схему

    Эксперимент 2. Изображения: гибридное transfer learning

    Замороженная ResNet18 (ImageNet) превращает изображение в 512 признаков, обучается только голова: классическая, квантовая или гибридная (Mari et al., 2020). Главный вопрос — поведение при малом объёме обучающих данных. Пока серия считается, на графике видны только уже готовые конфигурации.

    Эксперимент 5. Конечное число измерений

    На реальном квантовом процессоре ⟨Z⟩ оценивается по конечному числу измерений (shots), а градиенты — по правилу сдвига параметра. Здесь гибридная модель обучается именно так.

    Эксперимент 6. Barren plateaus

    Дисперсия градиента по параметру схемы при случайной инициализации. Экспоненциальное затухание с ростом числа кубитов делает обучение больших схем практически невозможным (McClean et al., 2018). Для глобальной функции стоимости эффект сильнее (Cerezo et al., 2021).
